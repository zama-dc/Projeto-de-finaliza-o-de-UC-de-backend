# 🚀 The Unsent Project - Versão Brasileira Replicada

> Um site inspirado no "The Unsent Project", onde você pode enviar mensagens de texto nunca enviadas antes de forma anônima.

<br>

## 📋 Requisitos do Projeto (Critérios Acadêmicos)
Para atender às exigências da disciplina, o projeto implementa:
* **Header**
* **Hero / Carrossel**
* **Footer**
* **Banco de Dados**
* **CRUD**
*  **Documentação**


<br>

## 🛠️ Tecnologias Utilizadas

| Camada do Projeto | Tecnologia |
| :--- | :--- |
| **Frontend** | HTML5, CSS3, JavaScript |
| **Backend** | PHP 8.x |
| **Banco de Dados** | MySQL (via PhpMyAdmin) |
| **Framework de Estilo** | Bootstrap 5.3 |

## ⚙️ Como rodar o projeto

Este projeto utiliza o ambiente **XAMPP** para simular um servidor local. Siga os passos abaixo:

### 1. Pré-requisitos
* **VS Code** ou outro editor de código de sua preferência.
* **XAMPP** instalado e configurado.

### 2. Configuração do ambiente
1. Abra o **Painel de Controle do XAMPP**.
2. Inicie as portas **Apache** e **MySQL**.
3. Navegue até a pasta de instalação do XAMPP (geralmente em `C:\xampp\htdocs`).
4. Extraia o ZIP diretamente no htdocs.

### 3. Configuração do Banco de Dados
1. Acesse [http://localhost/phpmyadmin](http://localhost/phpmyadmin) no seu navegador.
2. Crie um novo banco de dados chamado `para_segunda`.

### 4. Execução
1. Com o Apache rodando, abra o navegador e acesse: 
   `localhost/para_segunda (1)/`
2. Navegue até a pasta onde está o arquivo principal:
   `PHP/vitrine.php`
